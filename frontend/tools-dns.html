DNS 查询使用说明

本工具用于验证域名能否被正确解析。通过飞牛的 DNS 服务器查询 A / AAAA / CNAME / MX / NS 记录，快速区分是“域名解析问题”还是“网络连通问题”。

本工具用飞牛主机上配置的 DNS 服务器解析域名，返回 A / AAAA / CNAME / MX / NS 记录，用来判断域名解析是否正常。

工作原理

  • 查询由飞牛后端发起，走系统默认 DNS（/etc/resolv.conf）。
  • 依次查询 A（IPv4）、AAAA（IPv6）、CNAME（别名）、MX（邮件）、NS（权威服务器）。

使用步骤

  1. 输入域名，例如 www.baidu.com，不需要带 http://。
  2. 点击「查询记录」。

结果解读

  • 有 A 记录说明域名能解析到 IPv4 地址，这是浏览器访问的前提。
  • 返回 NXDOMAIN 表示域名不存在；返回空结果多为 DNS 服务器不可达或被拦截。
  • 如果这里能解析、但设备上打不开，问题通常在网关、代理或防火墙，而不是 DNS。
本工具只做查询，不修改飞牛或任何设备的 DNS 设置。

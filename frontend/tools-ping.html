Ping 检测使用说明

本工具用于检测从飞牛主机到目标主机的可达性与往返时延。通过 TCP 握手探测判断目标是否在线，可用于快速定位“这台设备到底通不通”的问题。

本工具从飞牛主机向目标发起 TCP 探测，用握手是否成功和耗时判断目标是否可达、往返时延有多大。

工作原理

  • 后端按顺序尝试与目标建立 TCP 连接，探测端口为 80、443、22、5666、5201。
  • 任意一个端口握手成功即判定目标可达，耗时记为本次延迟。
  • 不使用 ICMP，所以对端禁止 ping 时依然可以测；但也因此反映的是 TCP 建连时间，和系统 ping 的数值会略有差异。

准备工作

  • 目标需与飞牛在同一网络或可路由到达。
  • 目标上至少有一个常见服务端口处于监听状态，否则会被判为不可达。

使用步骤

  1. 输入目标 IP 或域名，例如 192.168.110.1、www.baidu.com。
  2. 填写探测次数（1-20 次），默认 4 次。
  3. 点击「开始检测」，等待结果输出。

结果解读

  • 每一行是一次探测：成功时给出耗时（毫秒），失败时标注不可达。
  • 末尾给出成功次数、平均/最小/最大时延。
  • 偶发几百毫秒的抖动通常来自对端排队或无线链路；持续超时先检查 IP、网段和目标服务。
这是「TCP 可达性探测」，不是 ICMP ping。若目标只开放 8080 等非常规端口，结果会显示不可达，属正常。
